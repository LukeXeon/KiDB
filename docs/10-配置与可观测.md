# 10 · 组件选型、配置（内置系统表）与可观测性

## 10.1 组件选型（全部开源，无公司私有依赖）

纪律：只引泛型/stdlib 接口库；并发与缓存优先 Go 官方扩展与大厂自用开源；能用 Redis 服务端能力就不引客户端库；**TiDB 侧只直接依赖独立模块 `pkg/parser`，其余为设计移植**（[13](13-TiDB复用清单.md)）。

| 组件 | 模块路径 | 验证版本 | 备注 |
|---|---|---|---|
| Redis 客户端 | **KvClient 接口 + `github.com/redis/go-redis/v9` 参考适配器** | v9.22.0 | 可替换；其他客户端经适配器接入（[09](09-后端契约与适配器.md) §9.3） |

自写薄层：分布式锁（~30 行，`SET NX PX` + `lock_release.lua`/`lock_renew.lua`）、BucketMap 版本校验、Lua 脚本注册器（embed 加载 + 启动期压缩：Go 生态无现成 Lua minifier，自写 lexer 级去注释/空白薄层，EVAL 下发字节量 -42%）、slot tag 表（sigurn/crc16）、配置存储（§10.2）、近缓存底座 otter（[08](08-自治治理与热Key.md) §8.4）、前置分类器（[02](02-SQL服务器.md) §2.2）。

**注意**：方案不引入任何配置解析库——配置即数据，存于 Redis 自身（§10.2）。

## 10.2 配置即数据：内置系统表（集群共享一份配置）

**设计动机**：本地配置文件对集群没有意义——N 个网关实例各持一份 TOML 必然漂移。KiDB 的元数据（Catalog/BucketMap）本来就存在 Redis 里、走"本地缓存+版本校验"，配置走完全相同的道路：**一个集群，一份配置，SQL 即管理面**（对齐 TiDB 的 `mysql.*` 系统表定位，但存储落 Redis 而非 TiKV）。

### 存储

| Key | 类型 | 内容 |
|---|---|---|
| `cfg:global` | Hash | field=变量名，value=msgp 编码值；特殊字段 `_ver`（单调递增版本）、`_audit`（最近修改者/时间） |

### SQL 管理面（复用 MySQL 变量语义）

go-mysql-server 原生实现 system variable 机制，将其持久化后端挂载到 `cfg:global` 即可：

```sql
SHOW GLOBAL VARIABLES LIKE 'bucket\_split\_%';
SET GLOBAL bucket_split_members = 60000;
SET GLOBAL query_allow_fullscan_tables = 't1,t2';
SELECT @@global.sweeper_batch;
```

> **命名纪律**：变量名一律小写下划线（`max_connections` 同款 MySQL 惯例）。不用点号——`SET GLOBAL a.b = 1` 中的点号有被解析器当成"库.表.列"限定标识符的风险。

- **任何 MySQL 客户端/GUI 都能直接管理配置**——配置管理面与数据面同一协议，不需要额外运维通道；
- `SET SESSION` 支持会话级覆盖（如单次查询临时允许全扫），不落 `cfg:global`（[02](02-SQL服务器.md) §2.5）。

### 一致性与传播

- `SET GLOBAL` 经 `config_set.lua` 原子执行：校验期望 `_ver`（CAS）→ HSET 新值 → `_ver+1` → 追加 `_audit`；并发写冲突返回 stale 由客户端重试；
- 各实例本地缓存配置快照，与 Catalog/BucketMap 共用同一版本校验刷新循环（秒级传播，[06](06-元数据与Schema演进.md) §6.2）；查询路径按 1/64 采样顺带校验 `_ver`，热点变更快速收敛；
- 配置 schema 版本内嵌，前后兼容一个发布周期（同元数据演进纪律，[06](06-元数据与Schema演进.md) §6.4）。

### 变量表（全部天然热更新）

| 变量 | 默认 | 说明 |
|---|---|---|
| `schema_lease_ms` | 1000 | 元数据本地快照租约（[06](06-元数据与Schema演进.md) §6.2） |
| `bucket_split_members / _bytes / _qps_ratio` | 50000 / 8MB / 0.4 | 分裂阈值 |
| `bucket_merge_members / _sustain_periods` | 12500 / 3 | 合并阈值与持续周期 |
| `hotkey_replica_max / _refresh_interval` | 8 / 1s | L4 副本上限与刷新周期 |

| `hotkey_row_cache` | `false` | 行级读热点近缓存（[08](08-自治治理与热Key.md) §8.4 覆盖边界） |

| `retry_backoff_base_ms / _max_ms` | 50 / 2000 | 退避矩阵参数（[09](09-后端契约与适配器.md) §9.6） |

校验规则（SET 时执行，非法值拒绝）：`bucket_split_bytes` ≤ 16MB（rebalance 有界性红线）；`query_allow_fullscan_tables` 中的表名必须在 Catalog 存在；阈值类变量非负；`schema_lease_ms` ∈ [100, 10000]。

### 引导配置（进程级、不可共享、不落配置文件）

连接地址/凭据、连接池大小、读写超时、监听端口、账号表、TLS 开关、ReadWriteOnly——这些描述的是"这个进程怎么连上集群、怎么对外服务"，天然不属于共享配置。经 `NewKernel` 的 Bootstrap 注入（网关由启动参数/环境变量构造，见 `cmd/kidb-server`）。启动校验：`scatter` 预算 = `read_timeout × deadline_headroom`，超限拒绝启动。

## 10.3 指标体系

> **实现状态**：`metrics` 包落地全部系列（prometheus Registerer 注入，nil=no-op）；
> 已挂钩子：查询时长/扇出（exec）、回表校验拦截、L1 命中、stale 重试（txguard）、
> 清扫量（sweeper）、分裂/合并计数与角色变迁（controller）。

内核指标（prometheus，经接口注入）：

`query_duration_seconds{plan}`、`query_scatter_fanout`、`index_bucket_members{table,idx}`、`index_bucket_splits_total` / `merges_total`、`hotkey_replicas_active`、`sweeper_lag_rows` / `swept_total`、`nearcache_hit_ratio`、`async_index_log_backlog`、`rowiter_rows_filtered_total`（回表校验拦截量）、`fullscan_fallback_total`、`lua_stale_retry_total`（BucketMap version 冲突重试）、`lua_noscript_total`（EVALSHA miss 回退）、`config_set_total{result}`（配置变更/冲突计数）、`plan_cache_hit_ratio`、`plan_cache_stale_total`（版本失效重建数）、`schema_lease_refresh_total`、`ddl_job_duration_seconds{type}`、`contract_violation_total`（CROSSSLOT 等契约违例，应为 0）、`owner_role_transitions_total`（角色进出次数，watchdog 有效性观察）。

适配器层命令级 QPS/延迟/错误由适配器自带（go-redis 可接 otel/prometheus hook），与内核指标用同一集群标识 label 关联。

## 10.4 慢查询与 EXPLAIN

- 自定义 EXPLAIN 节点展示下推内容：命中索引、桶数、扇出、是否走副本/近缓存、是否下推 Lua（[02](02-SQL服务器.md) §2.8）；
- 慢查询日志含完整执行计划；无索引谓词（即使走了全扫白名单）强制告警；
- 双层定位：Redis 命令级慢日志（适配器侧）vs SQL 执行慢（内核侧）可分别下钻；
- 后续增强：对齐 TiDB statement summary 的"按指纹聚合的语句摘要表"——先以慢查询日志 + 指标覆盖，摘要表列入观察项。

## 10.5 日志规范

- 统一 `log/slog` 结构化日志，`trace_id` 贯穿 SQL→命令；
- Lua 脚本业务性返回（stale/duplicate）不记 error 级（属正常路径），仅计数 + debug；
- 网关为独立进程，日志输出由启动参数配置；`WithLogger` Option 供测试与带外工具注入 Handler。
